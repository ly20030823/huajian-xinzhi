# 🌼 用 GitHub 同步你的花笺

> 不需要服务器，也不需要在电脑上安装 Git。准备一个私有 GitHub 仓库，花笺会直接通过 GitHub API 收好你的 Markdown 和图片。

## 一、创建专用仓库

1. 登录 GitHub，点击右上角 `+`，选择 **New repository**。
2. 仓库名可以填写 `floral-notepaper-sync`。
3. 建议选择 **Private**，避免笔记被公开访问。
4. 勾选 **Add a README file**，默认分支保持 `main`。
5. 点击 **Create repository**。

仓库创建后，复制它的 HTTPS 地址，例如：

```text
https://github.com/你的用户名/floral-notepaper-sync.git
```

## 二、创建最小权限访问令牌

打开 GitHub：

**Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**

然后这样填写：

1. **Token name**：`Floral Notepaper Sync`
2. **Resource owner**：选择你自己的账号。
3. **Expiration**：建议 90 天或一年；到期后重新创建并在花笺中替换即可。
4. **Repository access**：选择 **Only select repositories**。
5. 只勾选刚创建的同步仓库。
6. 在 **Repository permissions** 中找到 **Contents**，选择 **Read and write**。
7. 不需要添加任何 **Account permissions**。
8. 点击 **Generate token**。

生成后的令牌通常只显示一次。请复制后直接粘贴到花笺，不要写进笔记、README，也不要发给其他人。

## 三、在花笺中连接

打开 **设置 → GitHub 多设备同步**：

1. 填写私有仓库地址。
2. 将访问令牌粘贴到“访问令牌”。
3. 分支填写 `main`。
4. 在“当前云端工作区”里填写一个好认的名字。默认会使用当前本地文件夹名，例如 `论文资料`。
5. 打开 **启用同步**。
6. 点击 **保存**。
7. 点击 **测试连接**。
8. 显示连接成功后，点击 **立即同步**。

首次同步后，仓库中会出现：

```text
workspaces/
└─ 论文资料/                    一个独立的云端工作区
   ├─ 文献调研/
   │  └─ 蓝牙攻击检测.md
   ├─ 项目记录/
   │  └─ 七月计划.md
   ├─ 随手记.md                未放入文件夹的笔记
   ├─ images/                  笔记使用的本地图片
   └─ manifest.json            文件夹、顺序、版本信息
```

一个 GitHub 仓库可以容纳多个本地工作区，例如 `论文资料`、`工作记录`、`生活随笔`。它们分别住在 `workspaces/` 下，不会互相上传、下载或删除文件。`README.md` 是仓库的门牌，可以自由修改；`workspaces/` 由花笺维护，平时不要手动移动里面的文件。

平时如果关闭了“自动同步”，可以直接点击主窗口顶栏中、快捷便签左边的同步按钮。它会先保存当前笔记，再立即完成一次双向同步。

## 四、连接第二台设备

1. 在另一台设备安装花笺。
2. 先用“打开文件夹”选择一个空文件夹，作为这个工作区在新设备上的本地位置。
3. 打开同步设置，填入同一个仓库地址、`main` 分支和令牌。
4. 点击 **读取云端**。花笺会列出仓库中已有的工作区。
5. 选择要下载的工作区，例如 `论文资料`；不要凭感觉新建一个近似名字。
6. 点击 **下载云端**。这个按钮只读取 GitHub，不会上传或删除云端文件。
7. 确认笔记已经出现后，再按需要打开 **启用同步**；日常双向合并使用 **立即同步**。

花笺只会下载你选中的工作区。以后再次打开这个本地文件夹时，它会记住与哪个云端工作区配对。

> **安全提示：**“下载云端”只允许用于没有笔记的本地文件夹。如果当前文件夹已经有笔记，花笺会拒绝下载，避免覆盖本地内容。

建议每台设备开始写作前先同步一次，结束后再同步一次。开启自动同步后，花笺也会按设定的间隔帮你完成这件事。

## 五、同时修改怎么办？

如果两台设备同时修改同一篇笔记，花笺不会悄悄覆盖其中一份，而会：

- 保留本机版本；
- 下载另一台设备的版本；
- 创建一篇标题带有 **“同步冲突副本”** 的新笔记。

你可以比较两份内容，整理完成后删除不需要的一份。

## 六、常见问题

### 测试连接成功，但没有同步

确认 **启用同步** 已打开并保存，再点击 **立即同步**。测试连接只检查仓库和令牌，不会上传笔记。

### GitHub 返回 403

通常是令牌权限不足。检查令牌是否选择了正确仓库，并确认：

```text
Repository permissions → Contents → Read and write
```

### 令牌过期

重新创建令牌，在花笺设置中粘贴新令牌并保存。笔记仓库不需要重新建立。

### 换电脑需要安装 Git 吗？

不需要。花笺直接连接 GitHub，电脑上没有 Git 也能同步。
