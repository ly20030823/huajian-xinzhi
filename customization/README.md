# 花笺自定义内容

这里的 Markdown 文件可以直接用记事本、Typora 或其他文本编辑器修改。保存后无需重新编译程序。

## `greetings.md`

控制主窗口左上角的随机问候语。每个无序列表项代表一句候选内容，例如：

```markdown
- 你好
- 今天也记下一点吧
```

花笺启动以及每次切换笔记时都会随机选择一句，并尽量避免连续重复。修改后需要重新启动花笺，之后的每次切换都会使用新的候选内容。

## `about.md`

控制“关于”面板的主要介绍内容。每次打开“关于”面板都会重新读取此文件，因此保存后关闭并重新打开面板即可看到变化。

可使用两个占位符：

- `{{version}}`：当前软件版本
- `{{year}}`：当前年份

面板下方的“花笺悄悄话”由程序随机生成；点击它可以换一句。

图片可以放在本文件夹中，并在 `about.md` 里使用相对路径，例如：

```markdown
![标志](logo.png)
```

## 可视编辑模式的 Markdown 支持

“内容编辑”模式支持常用 Markdown：标题、粗体、斜体、删除线、行内代码、链接、图片、引用、分隔线、有序/无序/任务列表、表格、代码块和 YAML Front Matter。

Markdown 没有唯一且包含所有扩展的“完整语法”。LaTeX 公式、脚注、原始 HTML、MDX/JSX、自定义指令和 Mermaid 等扩展，建议打开“显示 Markdown 源码”后编辑。其中部分内容可以在渲染视图中显示，但不一定能在可视编辑模式中直接修改。
