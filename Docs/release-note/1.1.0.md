# 花笺·新枝 1.1.0

第一截新枝，正式从纸边探出头来。🌱

这个版本基于 Floral Notepaper 继续开发，在保留轻巧本地笔记体验的基础上，
重新整理了编辑、文件管理、快捷便签、同步和文档阅读流程。

## 本次更新

- 新增白色“清纸”主题，并重新调整主界面、侧栏和内容编辑布局。
- 默认使用所见即所得内容编辑，可按需显示 Markdown 源码并双向同步滚动。
- 完善列表、引用、任务复选框、链接、表格、代码块、公式和 Mermaid 流程图。
- 新增真实文件夹工作区、文件夹归类以及文件/文件夹拖动排序。
- 新增 GitHub 多设备同步，按本地工作区隔离云端目录，并提供安全的独立下载按钮。
- 快捷便签支持从当前笔记直接打开、只读锁、解锁编辑、保存、置顶和主题同步。
- 新增 DOCX 导入并转换为可编辑 Markdown，同时隐藏保留 Word 原件。
- 新增 PDF 导入与内置阅读器，支持搜索、翻页、缩放和复制文字。
- 新增图片粘贴、PDF 导出、查找替换、字数/行数/选区统计和磁盘刷新。
- 加入一只可以隐藏的趴趴橘猫；它不负责写作，只负责监督。
- 提供 Windows 中文安装程序，以及基于 GitHub Release 的后续更新链路。

## 下载提示

Windows 用户请选择文件名带有 `x64-setup.exe` 的安装程序。便携版不会自动安装
后续更新，更推荐使用安装版。
