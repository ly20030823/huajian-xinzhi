# 花笺·新枝 1.1.5

这一版为花笺增加 Ubuntu 24.04 支持。

## 新增

- 提供适用于 Intel/AMD 64 位电脑的 Ubuntu 24.04 `.deb` 安装包。
- Ubuntu 可以从当前 GitHub 仓库检查并下载更新；校验完成后会打开系统安装器，由用户确认升级。
- GitHub 同步令牌在 Ubuntu 上通过系统密钥环持久保存。
- 设置中的快捷键显示能够识别 Linux；Wayland 下的全局快捷键仍属于非必需实验功能。

## 安装提示

Ubuntu 用户请选择文件名以 `_amd64.deb` 结尾的安装包，使用“应用中心”打开并安装。升级程序只替换应用文件，不会主动删除笔记、同步设置或每日记录。
